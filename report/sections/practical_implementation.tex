\subsubsection{Stage 1: Data Loading and Preprocessing}

\noindent\textbf{(a)}
\begin{enumerate}[label=\roman*., topsep=0pt, itemsep=2pt]
    \item Tokenisation and lowercasing: Tokenisation involves dividing text into smaller units called tokens. These tokens can be in the form of words, characters, sub-words or sentences.
          It helps improve interpretability of text by different models. Lowercasing ensures words such as "Hello" and "hello" are treated as the same feature. These two steps reduces
          vocabulary size and inconsistency which in turn helps the model generalise better.
    \item Stopword removal: Stopwords are common words such as "the", "is", "and" etc. These words carry very little sentiment meaning. By removing these words, it helps reduce dimensionality
          which allows the model to focus on words that have more sentiment value. This results in better overall model performance.
    \item Stemming or Lemmatisation: Stemming cuts words to their root by trimming prefixes or suffixes. Lemmatisation uses linguistic rules to return meaningful base words (lemmas).
          Stemming is performed on each word independently whereas Lemmatisation is context aware. Lemmatisation was chosen for this use case since it preserves meaning more accurately than
          Stemming. This is especially important in sentiment analysis (like this movie review scenario) since it is sensitive to meaning.
    \item Data Splitting: Stratified sampling ensures that each split has the same class distribution. This prevents class imbalance bias from happening in any of the splits and ensures a
          fair evaluation is performed. Table \ref{class_counts} indicates the class counts in each split:
            \begin{table}[htbp]
            \caption{Class counts per dataset split}
            \centering
            \begin{tabular}{lcc}
            \hline

            \hline
            Training   & 700 & 700 \\
            Validation & 150 & 150 \\
            Test       & 150 & 150 \\
            \hline
            \end{tabular}
            \label{class_counts}
            \end{table}
\end{enumerate}

\noindent\textbf{(c)}
\begin{enumerate}[label=\roman*., topsep=0pt, itemsep=2pt]
    \item The model using L1 regularisation (ii) outperformed the model using L2 regularisation (i). For a linear SVM model (optimal model), sparse features are generally easier to separate
    than dense features. L1 regularisation zeroes out less important features creating a more sparse feature space. L2 regularisation on the hand, shrinks less important features but 
    rarely to zero. Hence, it keeps all the features and since it is more dense than the L1 model, it makes it harder for the linear SVM model to distinguish between the two classes.

    \item Table \ref{embedding_results} indicates the results from the best SVM configuration on embedding features:
        \begin{table}[htbp]
        \caption{Results of best SVM configuration on embedding features}
        \centering
        \begin{tabular}{cc}
            \hline
            \textbf{F1-score} & \textbf{AUC-ROC} \\
            \hline
            0.6730 & 0.7216 \\
            \hline
        \end{tabular}
        \label{embedding_results}
        \end{table}

        From Table \ref{embedding_results} it can be seen that the F1-score and AUC-ROC is more than 10\% lower than the results obtained from using the TF-IDF features. This implies that
        embedding features performed worse than TF-IDF features for this binary sentiment classification problem. The main reasons for this boils down to the data used, the task at hand and
        how each feature extraction method works. For the polarity dataset, there are only 2000 reviews which is very little for a generalised pretained sentence transformer model to pick
        up on the specifics needed for movie sentiment analysis. In addition, the task itself, sentiment analysis, may be an issue. TF-IDF assigns very high weights for words that strongly
        correlate to positive or negative reviews. Embeddings on the other hand, can give similar words that represent either positive or negative reviews similar vectors. This ultimately
        results in a blurred sentiment intensity. Lastly, TF-IDF produces a score for each word in the dataset, this produces a sparse feature space. 
        Embeddings, however, produce a dense feature space. Since, embedding features are more compressed, this makes it hard for a simple linear SVM to discriminate between the two classes.

\end{enumerate}

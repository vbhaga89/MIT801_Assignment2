\subsubsection{Stage 1: Data Loading and Preprocessing}

\begin{enumerate}[label=\roman*.]
    \item Tokenisation and lowercasing: Tokenisation involves dividing text into smaller units called tokens. These tokens can be in the form of words, characters, sub-words or sentences.
          It helps improve interpretability of text by different models. Lowercasing ensures words such as "Hello" and "hello" are treated as the same feature. These two steps reduces
          vocabulary size and inconsistency which in turn helps the model generalise better.
    \item Stopword removal: Stopwords are common words such as "the", "is", "and" etc. These words carry very little sentiment meaning. By removing these words, it helps reduce dimensionality
          which allows the model to focus on words that have more sentiment value. This results in better overall model performance.
    \item Stemming or Lemmatisation: Stemming cuts words to their root by trimming prefixes or suffixes. Lemmatisation uses linguistic rules to return meaningful base words (lemmas).
          Stemming is performed on each word independently whereas Lemmatisation is context aware. Lemmatisation was chosen for this use case since it preserves meaning more accurately than
          Stemming. This is especially important in sentiment analysis (like this movie review scenario) since it is sensitive to meaning.
    \item Data Splitting: Stratified sampling ensures that each split has the same class distribution. This prevents class imbalance bias from happening in any of the splits and ensures a
          fair evaluation is performed. Table \ref{class_counts} indicates the class counts in each split:

            \end{table}


\end{enumerate}

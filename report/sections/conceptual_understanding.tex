\section{Section A: Conceptual Understanding}

\subsection{Question 1: Regularistion and Overfitting}

\begin{enumerate}[label=\textbf{(\alph*)}, leftmargin=*, align=left]
    \item Overfitting occurs when a model learns the characteristics of the training set too closely resulting in the model not learning underlying general patterns. As a result, 
          the model fails to generalise when exposed to an unseen (test) dataset \parencite{geron2019hands}.
    
          For a sentiment classifier trained on the Polarity Dataset v2.0, two observable signs of overfitting the training data would be a poor F1-score and a low AUC-ROC score for a test set.
          A low F1-score indicates poor Precision and poor Recall which implies that the model has a high number of false positives and false negatives. Another sign would be a low AUC-ROC score.
          This indicates how close a model is to being perfect and indicates the ratio of true positives to false positives. An AUC-ROC score of close to 0.5 would indicate a model that is not that
          much better than a random model. This can be as a result of memorising specific words, phrases or patterns from the training set reviews.

          Overfitting is especially an issue in high-dimensional text feature spaces. As the dimension increases, data becomes more spread out which can make it harder for the model to 
          learn general patterns resulting in the model memorising instead. In addition, there can be instances in which the model finds rare words that may appear predictive in training
          but are actually noise due to each word being treated as a feature. Lastly, many features (words) may not even be present in some reviews. The model can overemphasise these words
          also resulting in the model learning noise and hence overfitting.

    \newpage
    
    \item   Table \ref{reg_comp} illustrates the comparision between L1 and L2 regularisation \parencite{geron2019hands}:
    
            \begin{table}[htbp]
            \caption{L1 vs L2 Regularisation}
            \centering
            \begin{tabularx}{\columnwidth}{p{5.2cm}YY}
            \hline
            \textbf{Dimension} & \textbf{L1 Regularisation} & \textbf{L2 Regularisation} \\
            \hline

            \label{reg_comp}
            \end{table}

    \item   \begin{enumerate}[label=\roman*., topsep=0pt, itemsep=2pt]
                \item \textbf{Advantage:} L1 regularisation reduces irrelevant features (words) by setting their associated weights to zero. This creates a sparse data set which helps an SVM distinguish between
                      classes.

                      \textbf{Disadvantage:} L1 is rather unstable when features are correlated (similar words). L1 may select one feature and discards others, leading to loss of useful complimentary signals.
                      This can cause more variance in model performance across different training sets.
                    
                \item L2 regularisation is more appropriate when correlated features are present. Hence, when the goal is to achieve a robust model. L2 distributes weight across correlated features rather
                      than just choosing one. This creates a smoother decision boundary and helps the model generalise when many words have sentiment information that overlaps.
            \end{enumerate}
    
\end{enumerate}

\subsection{Question 2: Feature Extraction for Text Classification}

\begin{enumerate}[label=\textbf{(\alph*)}, leftmargin=*, align=left]
    \item \textbf{Feature selection} is a technique in which a subset of the original features are chosen. This method simply reduces the feature space by just selecting the best features from
          the original feature space. Since only a subset is chosen, the features are still interpretable since they have not been altered. For text data, using
          TF-IDF, the individual words are still retained. Hence, feature selection is preferred for text data where semantic meaning is important.

          \textbf{Feature extraction} is a technique in which new features are created by transforming the original features. This technique reduces dimensionality by creating a more compact 
          feature space by transforming the original feature space. The resulting features are also interpretable as well however will have lower levels of 
          interpretability than feature selection because of the feature space now being a transformed version of the original space. Feature extraction is better for capturing underlying
          context such as word similarities. This is not suitable for text data in which semantic meaning is important since the new features may not have direct semantic meaning that a
          feature set with feature selection would have.
    
    \item \textbf{TF-IDF Vectorisation:} This method converts text into numerical vectors by measuring a word's importance within a document relative to all the documents (corpus). Basically,
          it weights how frequent a word is in a document and how rare it is across all documents. The main strength of this method is that it highlights words with high semantic
          meaning while down-weighting common words will low semantic meaning. One disadvantage is that it does not take into account word order and context since words are seen
          as individual features. Thus, it cannot distinguish between phrases such as "bad" and "not bad" which can be very important in sentiment analysis. 
    
          \textbf{Embedding-based Features:} This method involves using a pretrained model that converts text into dense, numerical, low-dimensional vectors, where semantically similar words
          are mapped to nearby points in a vector space. One main advantage is that it can capture semantic similarity between words which can help generalisation (contextual awareness).
          A disadvantage of this method in particular with sentiment analysis is that by grouping similar words, it can weaken the overall sentiment indicators. This could potentially
          make it harder for SVM classifiers to create an appropriate decision boundary.

          \textbf{Bag of Words:} This method converts text into numerical vectors based on word frequency. It creates a feature space of unique words in all documents by representing each document
          by counting word occurrences. One main advantage is that it is simple and effective at extracting strong explicit sentiment words which is generally good enough for sentiment
          analysis. A disadvantage of this method is that it ignores word order and context just like TF-IDF vectorisation which may have a big impact in sentiment analysis when phrases such
          as "not good" and "not bad" for example are common.
    
\end{enumerate}

\subsection{Question 3: Support Vector Machines}

\begin{enumerate}[label=\textbf{(\alph*)}, leftmargin=*, align=left]
    \item For binary sentiment classification using an SVM, the decision boundary refers to the boundary (hyperplane) that separates the reviews into positive and negative based on their
          feature vectors. The margin refers to the distance between the boundary and the closest training points from each class. It indicates a confidence buffer around the decision boundary.
          The support vectors refer to the reviews that are the closest to the boundary which are used to determine the margin around the boundary. By maximising the margin, it reduces the 
          model's sensitivity to noise in the data. This creates a more stable, robust boundary which creates a model that is better at generalising \parencite{geron2019hands}.

    \newpage
    \item   \begin{enumerate}[label=\roman*., topsep=0pt, itemsep=2pt]
                \item The kernel trick maps data into a higher-dimensional feature space without ever computing that mapping explicitly. This lets the SVM learn non-linear decision
                      boundaries. It is computationally preferable to explicitly computing a high-dimensional feature mapping because it computes dot products between pair of points
                      in the high-dimensional space without directly transforming the data. This reduces time since this computation is generally efficient and it also reduces the need
                      to store transformed data \parencite{geron2019hands}.
                    
                \item \textbf{Linear:} By using TF-IDF, text data can be represented as a sparse, high-dimensional feature space. In this instance, classes are often linearly separable.
                      This works well for a linear kernel that will be able to create a boundary and margin that can distinguish between the two classes.
                
                      \textbf{Radial Basis Function (RBF):} The RBF kernel is useful for modelling the non-linear relationship between features. This is especially important if there 
                      are complex relationships between words that heavily contribute to the sentiment.
            \end{enumerate}
    
\end{enumerate}
